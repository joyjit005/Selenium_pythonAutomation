# Python Automation - Lab Assignments

## Lab Tasks

### Module 1 - Selenium Core & Advanced Interactions
1. Multi-Locator Challenge - log in using By.ID, By.NAME, and By.XPATH; validate redirect.
2. Synchronization & Explicit Waits - handle dynamic content using WebDriverWait (no time.sleep()).
3. Dynamic Dropdowns & Checkboxes - verify checkbox state and select from an autocomplete list.
4. JavaScript Alerts and Confirms - handle Alert, Confirm, and Prompt dialogs.
5. HTML Web Table Extractor - iterate a table and extract a value by matching a row.
6. Windows, Tabs, and Iframes - interact inside an iframe and manage a new browser tab.

### Module 2 - Test Design & Reporting
1. Page Object Model (POM) Restructure - separate locators/actions from assertions.
2. Data-Driven Automation (DDT) - run login test cases from an external CSV file.
3. PyTest Integration with HTML Reporting - fixtures for setup/teardown, auto HTML report.

### Module 3 - BDD with Behave
1. Selenium + Behave BDD Setup - Gherkin scenario driving a real Selenium session.
2. Data-Driven Automation in Behave - Scenario Outline with an Examples table.
3. Selenium POM in the Behave Framework - Page Object Model used inside Behave steps.

### Module 4 - Robot Framework
1. Basic Syntax and Keywords - open browser, Input Text, Page Should Contain Element.
2. Variables and Data-Driven Automation - variables for credentials, data-driven test from an external file.
3. Custom Keywords and Libraries - custom Python keyword, BuiltIn library usage.
4. Assertions and Verification - UI assertion and API response assertion.
5. Test Setup and Teardown - suite-level login setup and logout teardown.
6. Tags and Test Execution - tagging tests, running with --include/--exclude, parallel execution.
7. Reports and Logs - HTML report generation and custom Log keyword usage.
