# Python Automation - Coursework & Capstone

Lab work, capstone project, and course certificates for the Python Automation
program, covering Selenium, PyTest, Behave (BDD), Robot Framework, and API
automation with Python Requests.

## Repository Structure

| Folder | Contents |
|---|---|
| [Lab Work](./Lab%20Work) | Module 1-4 lab reports with code, plus a README listing all lab tasks |
| [Capstone Project](./Capstone%20Project) | API Automation Framework (Requests + Behave), with README, report, and demo link |
| [Courses](./Courses) | Link to course completion certificates |

## Lab Work Overview

| Module | Topic |
|---|---|
| Module 1 | Selenium: locators, explicit waits, dropdowns and checkboxes, JS alerts, web tables, windows/tabs/iframes |
| Module 2 | Page Object Model, data-driven testing, PyTest with HTML reporting |
| Module 3 | BDD with Behave: Selenium setup, data-driven scenarios, POM with Behave |
| Module 4 | Robot Framework: keywords, variables, custom libraries, assertions, setup/teardown, tags, reports |

## Capstone Project
**API Automation Framework - User Management API.** A reusable framework built
with Python Requests and Behave, testing CRUD operations against the
JSONPlaceholder API, with Allure reporting.

## Tech Stack
Python, Selenium WebDriver, PyTest, Behave, Robot Framework, Requests, Allure
